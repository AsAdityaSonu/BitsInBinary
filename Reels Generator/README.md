# 🎥 Text Reel Generator  

🚀 **Say Goodbye to Manual Reel Editing!**  
This script automatically generates Instagram reels with a **question and multiple-choice options**, eliminating the need for manual editing.  

---

## 📌 Features  
- ✅ **Automated Reel Creation** – Just enter a question & options!  
- ✅ **No Manual Editing** – The script does everything for you.  
- ✅ **Custom Font & Logo Support** – Use your own branding.  
- ✅ **High-Quality Output** – Generates Instagram-ready reels (1080x1920).  

---

## 🎯 Example Output  
After running the script, an **Instagram-ready reel** will be saved as `output.mp4`.  
✅ **Question & options centered dynamically**  
✅ **Logo positioned perfectly at the bottom**  
✅ **Sleek & modern design**
