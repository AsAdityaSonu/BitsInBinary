# 📄 PDF Merge Tool  

🚀 **Easily Merge Multiple PDFs into One!**  
This script allows you to **automatically merge multiple PDF files** into a single document without any manual effort.  

---

## 📌 Features  
- ✅ **Batch PDF Merging** – Combine multiple PDFs into one seamlessly.  
- ✅ **Automated Sorting** – Ensures PDFs are merged in the correct order.  
- ✅ **Lightweight & Fast** – Merges PDFs quickly without quality loss.  
- ✅ **No External Tools Required** – Works with Python’s `pypdf` library.  
- ✅ **Custom Output Directory** – Save merged files where you want.  

---

## 🎯 How It Works  
1. **Place your PDFs** inside the `PDFs` folder.  
2. **Run the script** – It automatically detects and merges them.  
3. **Get your merged.pdf** inside the `OUTPUT` folder!  

✅ **No manual intervention required**  
✅ **Sorted automatically** based on filename  
✅ **Error handling for missing or corrupt files**  

---

## 🚀 Getting Started  

### 🔧 Prerequisites  
Ensure you have the following installed:  
- Python 3+  
- Required dependencies (install via `pip`):  
  ```sh
  pip install pypdf
  ```

## ▶️ Usage  
1. **Place your PDFs** inside the `PDFs` folder.  
2. **Run the script** using:  
   ```sh
   python main.py
   ```
3. Get the merged PDF inside the `OUTPUT` folder as `merged.pdf`.  

✅ No manual intervention required  
✅ Automatically sorted based on filename  
✅ Handles missing or corrupt files gracefully  

--- 

🛠 **Customization**  
- Modify the `input_folder` variable in `main.py` to change the source folder for PDFs.  
- Change the `output_file` path to save the merged PDF to a different location.  
- Customize the sorting logic to merge PDFs in a specific order.
